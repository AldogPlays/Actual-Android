# Actual-Android

Terms for connecting to an Actual Budget server and assessing the loaded page.

## Language

**Connection recovery**:
The process after a browser network load failure that checks the active server and may offer a configured fallback for review. A failed background connectivity check alone does not start connection recovery.
_Avoid_: Automatic failover

**Page diagnostics**:
Observations of the loaded server page's security context and browser capability presence. They do not establish working storage, budget initialization, or synchronization.
_Avoid_: Compatibility certification
